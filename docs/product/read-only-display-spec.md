# 内镜检查数据只读展示规范

> 产品范围基线：Issue #27  
> 医院：菏泽市肿瘤中医医院

## 1. 产品定位

系统从医院 IRIS/Caché 数据库读取内镜检查结果，根据配置关键词形成红、黄、
绿关注等级，并在医院内网提供只读查询和展示。

关注等级是管理标记，不是正式诊断或病情严重程度。系统不承担患者上报、消息
推送或处置闭环。

## 2. 页面结构

MVP 只使用一个主页面：

```text
顶部导航（仅内镜中心）
  └─ 工具区（最后同步时间、立即刷新、监测规则）
      └─ 筛选区
          └─ 五项汇总卡片
              └─ 检查结果列表
                  └─ 只读详情抽屉

监测规则按钮 → 居中规则配置弹窗
```

医院名称固定显示“菏泽市肿瘤中医医院”。隐藏首页、技师工作站、报告、统计、
排班、质量控制等其他系统菜单。

## 3. 筛选条件

| 筛选项       | 数据来源                     | 交互                           |
| ------------ | ---------------------------- | ------------------------------ |
| 检查日期范围 | `RISR_ReportDate`            | 必须提供开始和结束日期         |
| 科室         | 科室对象引用描述             | 下拉，可选择全部               |
| 患者类型     | `PAADM_Type`                 | 使用确认后的代码/中文名称      |
| 关注等级     | 匹配结果                     | 全部、红色、黄色、绿色、未分级 |
| 检查项目     | `RISR_ItemDesc`              | 下拉或可搜索下拉               |
| 姓名/关键词  | 姓名、报告内容、诊断、命中词 | 模糊搜索，需防止无界全文扫描   |

取消“报告状态”和“上报状态”筛选。

## 4. 汇总卡片

只显示五项，且必须与当前筛选条件一致：

1. 全部
2. 红色关注
3. 黄色关注
4. 绿色关注
5. 未分级

取消“待上报”卡片。点击卡片只改变关注等级筛选，不触发任何业务动作。

## 5. 列表字段

| 顺序 | 字段       | 展示规则                               |
| ---: | ---------- | -------------------------------------- |
|    1 | 关注等级   | 红/黄/绿/未分级文字标签，不能只靠颜色  |
|    2 | 姓名       | 按权限完整或脱敏显示                   |
|    3 | 科室       | 空值显示 `—`                           |
|    4 | 床号       | 门诊或空值显示 `—`                     |
|    5 | 类型       | 显示确认后的中文名称；未知时显示原代码 |
|    6 | 检查项目   | 完整名称，过长时省略并支持悬停查看     |
|    7 | 检查日期   | `YYYY-MM-DD`                           |
|    8 | 检查时间   | `HH:mm:ss`；缺失显示 `—`               |
|    9 | 命中关键词 | 显示全部命中词，按等级着色             |
|   10 | 操作       | 仅“查看详情”                           |

列表不展示长报告正文和诊断。默认按检查日期、检查时间降序；时间相同时红 > 黄

> 绿 > 未分级。

## 6. 只读详情抽屉

点击“查看详情”后从右侧打开抽屉，保持主页面筛选、排序和分页。

抽屉展示：

- 关注等级、姓名、科室、床号、患者类型。
- 检查项目、检查日期、检查时间。
- 报告内容。
- 诊断。
- 全部命中关键词、命中等级、命中字段和上下文高亮。

报告内容和诊断为空时显示统一占位，不隐藏整条记录。高亮不得改变原文。

抽屉中只允许关闭和阅读，不出现任何写操作。

## 7. 监测规则弹窗

规则配置继续保留，因为它决定关注等级，不属于患者上报动作。

- 可查询、新增、编辑、启用和停用关键词规则。
- 匹配字段调整为“报告内容”“诊断”“全部文本”。
- 多级命中取 RED > YELLOW > GREEN，同时保存和展示全部命中。
- 未命中任何规则为 UNCLASSIFIED，不能自动显示绿色。

## 8. 明确取消的字段和功能

当前数据源未提供，页面暂不展示：

- 住院号、性别、年龄。
- 报告审核状态和原始状态码。
- 报告保存、提交、审核和最后更新时间。
- 首次上报时间。

产品范围取消：

- 待上报、已上报、已知晓、已处理、误报。
- 标记上报、知晓、处理、误报及恢复按钮。
- 上报时间线、接收人、备注。
- 实时推送和日报。
- 导出日报入口。

代码、API、数据库和测试均不得保留可调用的隐藏上报入口。

## 9. 页面状态

必须提供：

- 首次加载、筛选加载和刷新状态。
- 空数据状态。
- 数据源不可用或同步失败状态。
- 最后成功同步时间。
- 分页和总数。

数据源异常时保留最近一次成功数据，并醒目标明数据可能延迟；不得把无数据与
同步失败显示成同一状态。

## 10. 验收要点

- 页面字段与九个已确认源字段一致。
- 五个汇总卡片与列表筛选口径一致。
- 列表和详情中不存在未经确认的审核字段。
- 全站不存在任何患者上报或处置入口。
- 红黄绿有文字和颜色双重表达。
- 1366×768 分辨率下筛选、汇总和首屏列表可用。
- 合成数据覆盖空科室、空床号、空诊断、未知患者类型和多关键词命中。
